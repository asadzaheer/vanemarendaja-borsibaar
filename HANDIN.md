## Merge Conflict Resolution
We encountered a merge conflict in our demo branch which was resolved by:
1. Identifying the conflicting changes
2. Reviewing both versions of the conflicting code
3. Deciding which changes to keep and which to overwrite
4. Manually editing the files to incorporate the desired changes
5. Committing the resolved conflicts
